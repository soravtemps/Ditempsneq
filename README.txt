DITEMPS CLEAN-URL STRUCTURE

Root:
/
  -> index.html

Templates:
  /templates/
  -> templates/index.html

Individual templates:
  /template/<slug>/
  -> template/<slug>/index.html

Legal:
  /legal/privacy-policy/
  /legal/dmca/
  /legal/about-us/
  /legal/terms/

Profile:
  /profile/
  -> profile/index.html

This structure is intended for clean directory URLs on hosts that support
index.html directory routing.
